# Раздел X — карта экранов

Интерактивная карта экранов раздела X: узлы — экраны, рёбра — переходы **по полям-сущностям**
(не по кнопкам). Связи привязаны `field -> field`, поэтому при перестановке карточек линии
следуют за полями.

**Стек:** React Flow (`@xyflow/react`) + `elkjs` (layout: `layered`, `direction: DOWN`), Vite + React + TypeScript.

## Запуск

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # tsc + production build (elkjs вынесен в ленивый чанк)
npm run export:schema  # -> section-x-screen-map.schema.json (то же, что кнопка «Экспорт JSON»)
```

## Взаимодействие

- **Hover по полю / линии / строке сущности** — подсвечивается весь маршрут сущности
  (поля на всех экранах + все её переходы, линии «маршируют» и показывают чип сущности), остальное затемняется.
- **Клик по сущности** в панели — закрепить (pin) подсветку; клик по холсту сбрасывает.
- **Клик по экрану** — спецификация: роут, API, состояния, поля со статусами и `name: type`,
  входящие/исходящие связи (кликабельны — прыжок к связанному экрану).
- **Легенда STATUS** — фильтр полей по статусу.
- **Редактирование схемы** — drag карточек (сетка 10 px), drag от порта создаёт новый переход
  поле→поле, `Delete` удаляет выбранную связь. «Сброс · хаб *» — исходная раскладка,
  «ELK · layered ↓» — авто-раскладка elkjs.
- **Экспорт JSON** — скачивает/копирует актуальную схему (включая текущие позиции и ручные связи):
  `meta` (стек, холст, компоненты, палитра), `screens[]` (спецификация + поля + порты),
  `entities[]` (маршруты), `edges[]` (field -> field). Образец — `section-x-screen-map.schema.json`.

## Данные и структура

Единственный источник истины — `src/data/schema.ts`: экраны, поля, сущности и рёбра.
Чтобы заменить «Платежи» на реальный раздел X, достаточно отредактировать `SCREENS` и `EDGE_DEFS` —
карта, панель и экспорт подхватят изменения.

```text
src/
  data/schema.ts        # экраны, поля-сущности, рёбра, палитра, buildExport()
  flow.ts               # EdgeDef -> React Flow edges (стороны портов, офсеты)
  layout/elk.ts         # elkjs: layered / DOWN / ORTHOGONAL (lazy import)
  components/
    ScreenNode.tsx      # card/screen + card/field + порты 5px
    OrthEdge.tsx        # ортогональный пунктир 3/4, r8, подсветка маршрута
    Inspector.tsx       # спецификация экрана / обзор раздела
    Icon.tsx            # иконки полей 12px
  App.tsx               # холст 1200×900, тулбар, легенда, экспорт
scripts/export-schema.ts
section-x-screen-map.schema.json   # сгенерированный образец экспорта
screenshots/                        # проверочные кадры (хаб, hover, инспектор, ELK)
```
